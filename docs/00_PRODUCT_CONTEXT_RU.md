# PersonalCRM — контекст продукта (RU)

## Назначение
PersonalCRM — облачный сервис «персональная CRM» для управления социальным капиталом.

## Источник истины
Кратко: **источник истины — OpenAPI + SQL**.
- API-контракт: `openapi/personalcrm_openapi_v1.yaml`.
- DB-контракт: `db/personalcrm_postgres_schema_draft.sql`.
- Код должен строго следовать этим контрактам. Любые изменения контрактов выполняются через PR с явным описанием причины.

## Роли
- Владелец (Owner): полный доступ.
- Ассистент (Assistant): доступ только к данным уровня Shared/Limited и с аудитом действий.

## Локализация
Интерфейс (frontend) полностью на русском языке: названия разделов, кнопок, подсказок, сообщений об ошибках.
