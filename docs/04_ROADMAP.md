# Roadmap PersonalCRM

## MVP (контракты + базовая ценность)
Цель: система уже полезна владельцу и ассистенту.
- Контакты: CRUD, поиск, фильтры, приватность.
- Взаимодействия: CRUD + таймлайн контакта.
- Интродукции: CRUD + валидации переходов статусов.
- Напоминания: CRUD + фильтры по срокам.
- Стратегия + колесо окружения: чтение/обновление.
- Проекты + участники.
- RBAC Owner/Assistant + audit log.

## Phase 1 (усиление операционки)
- Улучшенная аналитика: здоровье отношений, просроченные касания, отчёты.
- Массовые операции: импорт/дедупликация, batch updates.
- Расширение ролей и прав (permission-based).

## Phase 2 (интеграции и автоматизация)
- Интеграции: Google Calendar, email логирование, Telegram inbox (forward-to-bot).
- Автоматические каденции касаний (30/90/180) и триггеры.
- AI-ассистент (briefing к встрече, next-action предложения) при соблюдении приватности.
