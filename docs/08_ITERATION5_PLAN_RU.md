## Итерация 5 — «Продуктивность и масштабируемость»

Цель: ускорить ежедневные операции и упростить масштабируемость данных без изменения текущих контрактов по умолчанию.

### Основные направления
1) Импорт CSV контактов  
2) Дедупликация и слияние контактов  
3) Быстрый поиск (server‑side + UI)  
4) Экспорт (CSV/JSON)  
5) Ежедневный дайджест задач для ассистента/владельца  
6) Уведомления/напоминания (простые)

---

## Критерии готовности (Definition of Done)
- Импорт CSV работает на 1–5 тыс. контактов без таймаутов и с отчётом по ошибкам.
- Дедупликация находит дубли по email/телефону/имени и предлагает безопасное слияние.
- Поиск работает на сервере, UI использует server‑side фильтры, время ответа ≤ 500 мс на выборке 10k.
- Экспорт CSV/JSON формируется корректно, с фильтрами и без чувствительных полей для ассистента.
- Дайджест отображается в UI и может быть отправлен по email/как отчёт (MVP).
- Уведомления не блокируют UI и отражают статус действий.
- Все тексты на русском, тесты и check:ru зелёные.

---

## План задач

### 1) Импорт CSV контактов
- Backend:
  - Endpoint для загрузки CSV (multipart).
  - Валидация: обязательные поля, формат email/телефона, ограничение размера.
  - Асинхронная обработка (фон/очередь) или пакетная вставка.
  - Результат: количество созданных/обновлённых/ошибок.
- Frontend:
  - UI для загрузки CSV, прогресс/статус.
  - Список ошибок по строкам.
- Тесты:
  - E2E загрузка CSV с 5 контактами и одной ошибкой.

### 2) Дедупликация и слияние
- Backend:
  - Правила совпадений: email, телефон, похожие имена.
  - Endpoint: список кандидатов на слияние.
  - Endpoint: операция merge (источник + цель).
  - Логирование в audit.
- Frontend:
  - UI списка дублей и экран слияния.
  - Предпросмотр конфликтов полей.
- Тесты:
  - E2E: создать 2 контакта‑дубликата → merge → остался один.

### 3) Быстрый поиск (server‑side + UI)
- Backend:
  - Поддержка `q` в /contacts с индексами.
  - Индексы по email/phone/display_name.
  - Пагинация и сортировки.
- Frontend:
  - Переключение поиска на server‑side.
  - Debounce + индикатор загрузки.
- Тесты:
  - E2E: поиск возвращает корректные контакты.

### 4) Экспорт CSV/JSON
- Backend:
  - Endpoint экспорта с фильтрами и пагинацией.
  - Учитывать visibility/RBAC.
- Frontend:
  - Кнопки экспорта.
  - Скачивание файла с корректным именем.
- Тесты:
  - E2E: экспорт CSV, проверка корректности заголовков.

### 5) Ежедневный дайджест задач
- Backend:
  - Endpoint /digest (MVP).
  - Формирование списка просрочек, ближайших напоминаний, интродукций.
- Frontend:
  - Экран дайджеста + маркеры «готово».
- Тесты:
  - E2E: данные из API отображаются.

### 6) Уведомления/напоминания (простые)
- Backend:
  - Мини‑шедулер/cron (MVP) для «напоминаний сегодня».
- Frontend:
  - Визуальные подсказки и события.
- Тесты:
  - E2E: событие видимо в UI.
