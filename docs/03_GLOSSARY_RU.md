# Глоссарий (RU)

- **Контакт** — карточка человека с каналами связи, контекстом знакомства и атрибутами отношений.
- **Организация** — компания/структура, к которой относится контакт.
- **Взаимодействие** — любое касание с контактом: встреча, звонок, сообщение, событие.
- **Таймлайн** — хронологическая лента взаимодействий по контакту.
- **Интродукция** — процесс знакомства двух людей через посредника с согласиями сторон и отслеживанием результата.
- **Напоминание** — задача/сигнал на действие: связаться, поздравить, сделать follow-up.
- **Стратегия** — описание целей и подхода к развитию окружения.
- **Колесо окружения** — 9 сегментов окружения с текущими и целевыми уровнями.
- **Проект** — совместная активность/инициатива с участниками из контактов.
- **Owner (Владелец)** — пользователь с полным доступом.
- **Assistant (Ассистент)** — делегат с ограниченным доступом.
- **Приватность записи** — режим доступа: private/shared/limited.
