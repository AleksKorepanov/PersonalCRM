# PersonalCRM — требования (RU)

## 1) Обязательные принципы
1. **Contract-first**: источник истины — **OpenAPI + SQL**, реализация строго соответствует:
   - `openapi/personalcrm_openapi_v1.yaml`
   - `db/personalcrm_postgres_schema_draft.sql`
2. **Интерфейс полностью на русском языке**.
3. **Multi-tenant**: все сущности принадлежат `workspace`.
4. **Роли**: Owner и Assistant. У ассистента ограниченный доступ.
5. **Приватность записи**: `private | shared | limited`.
6. **Soft delete**: через `deleted_at` (кроме технических таблиц).
7. **Audit log**: фиксировать действия ассистента и ключевые операции.

## 2) Сущности и ключевые поля (MVP)
### Контакты (contacts)
- ФИО, каналы связи, организация
- теги/сегменты, уровень близости/доверия
- контекст знакомства (дата/место/источник)
- приватность записи

### Взаимодействия (interactions)
- тип (встреча/звонок/сообщение)
- дата/время, итог, следующий шаг
- привязка к контакту

### Интродукции (introductions)
- кто с кем соединяется, цель
- статусы и согласия сторон

### Напоминания (reminders)
- тип/статус, срок выполнения
- привязка к контакту или проекту

### Стратегия и колесо окружения (strategy, wheel)
- текст стратегии
- сегменты колеса: текущий и целевой уровень

### Проекты (projects)
- название, описание, статус
- участники (связь с контактами)

## 3) MVP-функциональность
1. CRUD контактов + поиск и фильтры.
2. Таймлайн взаимодействий по контакту.
3. CRUD интродукций с валидацией переходов статусов.
4. CRUD напоминаний + фильтры по срокам.
5. Стратегия + колесо окружения (чтение/обновление).
6. Проекты + участники.
7. RBAC (Owner/Assistant) + приватность + аудит.

## 4) Не входит в MVP (позже)
- Полные интеграции (Gmail/Telegram/LinkedIn) кроме заготовок.
- AI-ассистент.
- Продвинутый граф связей.

## 5) Критерии приемки
- `docker compose up --build` без ошибок.
- Миграции применяются: `alembic upgrade head`.
- Автотесты зелёные: `pytest -q`.
- UI запускается и все тексты на русском.
