# Журнал изменений

Этот файл ведётся вручную и описывает изменения по версиям.

## Правила ведения

- Версионирование: SemVer `vX.Y.Z`.
- Записи добавляются сверху вниз (новое сверху).
- До релиза изменения фиксируются в разделе **[Не выпущено]**.
- Перед релизом переносите изменения в новый блок версии.
- Каждый пункт — кратко, по сути, без деталей реализации.
- По возможности указывайте ссылки на задачи/PR.

## Формат записи

### [Не выпущено]

- Добавлено: ...
- Изменено: ...
- Исправлено: ...
- Безопасность: ...

### [vX.Y.Z] — YYYY-MM-DD

- Добавлено: ...
- Изменено: ...
- Исправлено: ...
- Удалено: ...
- Безопасность: ...

## [Не выпущено]

- Добавлено: базовый release pipeline для сборки Docker-образов.
